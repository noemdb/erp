# Manual del contador

1. Revisa el período en Períodos → detalle: el checklist debe estar en verde (lotes, NC con afectado, retenciones emitidas).
2. **Reglas:** Reglas → crea borradores con fuente y vigencia → revisión → aprobación → activación (cierra la anterior sin editarla).
3. **Retenciones:** prepara desde compras/pagos elegibles → revisa `explanation[]` en la previsualización → emite (número único, snapshot+hash) → entrega con fecha. Anular exige motivo y no libera número; para corregir, anula y emite sustituto.
4. **Cierre:** congela versión del resumen (Resumen IVA → Congelar) → Cierra. Reapertura solo con motivo; todo queda en bitácora.
5. **Conciliación:** Resumen IVA muestra controles F8; cualquier hallazgo debe resolverse o justificarse por escrito.
6. Descargas: CSV en cada libro/reporte; bitácora exportable en Auditoría.
